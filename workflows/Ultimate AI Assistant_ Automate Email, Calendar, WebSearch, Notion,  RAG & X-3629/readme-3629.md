### 🚀 Cách import & Lưu ý khi "lên đồ"

#### 1. Import Workflow 📥
Hướng dẫn import từ file JSON hoặc copy/paste JSON vào n8n Editor.

#### 2. Các lưu ý (BẮT BUỘC) phải chỉnh 📌
Phân tích cụ thể các node quan trọng cần cấu hình trong workflow:
- **Telegram Trigger**: Cấu hình webhook để nhận tin nhắn từ Telegram.
- **OpenAI**: Cấu hình API Key của OpenAI để sử dụng các tính năng AI.
- **Pinecone Vector Store**: Cấu hình API Key của Pinecone để lưu trữ vector.
- **Gmail Tool**: Cấu hình tài khoản Gmail để quản lý email.
- **Google Calendar Tool**: Cấu hình tài khoản Google Calendar để quản lý lịch.
- **Notion Tool**: Cấu hình tài khoản Notion để ghi chú.
- **Twitter Tool**: Cấu hình tài khoản X (Twitter) để đăng bài.
- **Tavily WebSearch**: Cấu hình API Key của Tavily để tìm kiếm web.

#### 3. Kích hoạt ⚡️
- Test run dữ liệu mẫu.
- Bật Active workflow.
