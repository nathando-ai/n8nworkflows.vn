### 🚀 Cách import & Lưu ý khi "lên đồ"

#### 1. Import Workflow 📥
1. Truy cập trang [Star Wars Language Translation API for AI Agents](https://n8n.io/workflows/5638).
2. Nhấn nút "Download" để tải file JSON của workflow.
3. Trong n8n Editor, nhấn vào "Import from File" và chọn file JSON vừa tải về.

#### 2. Các lưu ý (BẮT BUỘC) phải chỉnh 📌
Phân tích cụ thể các node quan trọng cần cấu hình trong workflow:
- **Starwars Translations MCP Server**: Node này là điểm bắt đầu của workflow. Các sếp cần cấu hình đúng các tham số đầu vào để workflow hoạt động chính xác.
- **Translate to Cheunh, Translate to Gungan, Translate to Huttese, Translate to Mandalorian, Translate to Sith, Translate to Yoda**: Các node này thực hiện dịch ngôn ngữ từ tiếng Anh sang các ngôn ngữ Star Wars tương ứng. Các sếp cần đảm bảo rằng các API dịch ngôn ngữ đã được cấu hình đúng và hoạt động bình thường.

#### 3. Kích hoạt ⚡️
- Test run dữ liệu mẫu để đảm bảo workflow hoạt động đúng.
- Bật Active workflow để bắt đầu dịch ngôn ngữ tự động.
