### 🚀 Cách import & Lưu ý khi "lên đồ"

#### 1. Import Workflow 📥
Tải file JSON của workflow này từ n8n.io (Link gốc: [Workflow #4774](https://n8n.io/workflows/4774)) và import trực tiếp vào n8n Editor của các sếp, hoặc sử dụng tính năng copy/paste JSON.

#### 2. Các lưu ý (BẮT BUỘC) phải chỉnh 📌
Các sếp cần cấu hình chính xác các node trọng điểm sau:

- **Submit Form with Keyword, Business Info, Industry (`formTrigger`):** Node khởi đầu, cung cấp một giao diện web dạng form để các sếp nhập từ khóa tìm kiếm TikTok, thông tin doanh nghiệp và lĩnh vực hoạt động.
- **Scrape Data from TikTok through Keyword by BrightData (`httpRequest`):** Cấu hình API endpoint và Headers của Bright Data để kích hoạt tiến trình cào profile theo từ khóa.
- **3 Minute Wait Time (`wait`):** Khoảng thời gian chờ (3 phút) để hệ thống Bright Data xử lý và tạo snapshot dữ liệu.
- **Extract Data from Snapshot Generated by BrightData (`httpRequest`):** Gọi API lấy kết quả snapshot trả về danh sách influencer thô (ID, lượng follower, mô tả kênh...).
- **Update Data in the Google Sheet (`googleSheets`):** Kết nối tài khoản Google Sheets thông qua `googleSheetsOAuth2Api` để lưu trữ danh sách influencer thô vừa cào được.
- **Find the Collaborator (`agent`) & Anthropic Chat Model (`lmChatAnthropic`):** 
  - Chọn credentials `anthropicApi`.
  - Đảm bảo model được chọn là **Claude 4 Sonnet** (`claude-sonnet-4-20250514`) để AI phân tích độ phù hợp của từng influencer đối với sản phẩm/doanh nghiệp.
- **Code (`code`):** Node xử lý mã nguồn JavaScript dùng để parse output dạng markdown của Claude AI thành định dạng JSON chuẩn hóa.
- **Google Sheets1 (`googleSheets`):** Cập nhật kết quả phân tích của AI (trạng thái hợp tác, điểm số, nhận xét) vào bảng Google Sheets.
- **Filter (`filter`):** Bộ lọc thông minh chỉ giữ lại những Influencer được đánh giá là **"Highly Relevant"** (Độ phù hợp cao).
- **Gmail (`gmail`):** Kết nối `gmailOAuth2` để tự động soạn và gửi email mời hợp tác đến các influencer đã vượt qua vòng lọc.

#### 3. Kích hoạt ⚡️
- Nhấn **Execute Workflow** và điền thử thông tin vào Form đầu vào để test run.
- Kiểm tra xem dữ liệu có được đẩy vào Google Sheets và email có được gửi đi chính xác hay không.
- Bật công tắc **Active** để đưa workflow vào vận hành tự động 24/7.
