### 🔧 Yêu cầu cần thiết
:::info[CHUẨN BỊ]
- Tài khoản YouTube đã kích hoạt API và có quyền đăng tải.
- API Key của YouTube (có thể lấy từ Google Cloud Console).
- Danh sách URL hoặc ID của các video ngắn cần xử lý.
:::

### 🚀 Cách import & Lưu ý khi "lên đồ"

#### 1. Import Workflow 📥
1. Truy cập vào n8n Editor.
2. Nhấn vào nút "Import from URL" và dán link: [https://n8n.io/workflows/3007](https://n8n.io/workflows/3007).
3. Hoặc tải file JSON về và import thủ công.

#### 2. Các lưu ý (BẮT BUỘC) phải chỉnh 📌
- **Fill information to Start**: Cấu hình form để nhập thông tin cần thiết (URL video, tiêu đề, mô tả...).
- **Extract Shorts**: Cấu hình HTTP Request để lấy dữ liệu từ nguồn video ngắn.
- **Filter the Best Shorts to Upload**: Sửa đoạn code trong node này để lọc những video ngắn có tiềm năng cao nhất.
- **Upload to your YouTube Account**: Cấu hình credentials YouTube và điền thông tin cần thiết (Channel ID, Playlist ID...).

#### 3. Kích hoạt ⚡️
- Test run dữ liệu mẫu trước khi kích hoạt.
- Bật Active workflow sau khi đã cấu hình đầy đủ.
