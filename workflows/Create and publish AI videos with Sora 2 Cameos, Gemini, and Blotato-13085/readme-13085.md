## **🚀 Cách Import & Lưu Ý Khi "Lên Đồ"**

### **1. Import Workflow 📥**
#### **Phương pháp 1: Import từ File JSON**
1. **Tải workflow** từ [link gốc](https://n8n.io/workflows/13085) hoặc sao chép JSON từ canvas.
2. **Trên n8n Editor**, nhấn **Import** → **Paste JSON**.
3. **Chọn workspace** muốn lưu và nhấn **Import**.

#### **Phương pháp 2: Copy/Paste JSON**
1. Mở **n8n Editor** → **Create New Workflow**.
2. Nhấn **Import** → **Paste JSON** và dán toàn bộ mã JSON từ workflow.
3. **Lưu workflow** với tên `AI_Video_Generator`.

---
### **2. Các Lưu Ý BẮT BUỘC Phải Chỉnh 📌**

#### **🔹 1. Cấu Hình Google Sheets**
- **File Google Sheets** phải có **các cột sau**:
  - `Viral_Idea` (dữ liệu đầu vào)
  - `Status` (trạng thái: `Pending`, `Success`, `Error`)
  - `Video_URL` (đường dẫn video sau khi sinh)
  - `Platform` (TikTok/Facebook/Instagram)
- **Chia sẻ quyền** cho n8n với vai trò **Editor**.

#### **🔹 2. Cấu Hình Google Gemini API**
- **Tạo API Key** tại [Google AI Studio](https://aistudio.google.com/).
- **Thêm credentials** trong n8n:
  - **Tên credentials**: `googlePalmApi`
  - **API Key**: Dán key từ Google.
- **Kiểm tra** trong node `Analyze Viral Idea` và `Gemini LLM`.

#### **🔹 3. Cấu Hình Sora 2 Cameos**
- **Chọn Cameos** trên [Sora2.com](https://sora2.com/) và ghi lại **ID Cameos**.
- **Thêm credentials HTTP Header Auth**:
  - **Tên credentials**: `httpHeaderAuth`
  - **Header**:
    ```
    Authorization: Bearer YOUR_SORA_API_KEY (nếu có)
    Sora-Cameos-ID: YOUR_CAMEOS_ID
    ```
- **Kiểm tra** trong node `Generate Sora Video`.

#### **🔹 4. Cấu Hình Blotato (TikTok/FB/IG)**
- **Tạo API Key** tại [Blotato](https://blotato.com/).
- **Thêm credentials**:
  - **Tên credentials**: `blotatoApi`
  - **API Key**: Dán key từ Blotato.
- **Cấu hình OAuth 2.0** cho mỗi nền tảng:
  - **TikTok**: Cần **Client ID & Secret**.
  - **Facebook**: Cần **Page Access Token**.
  - **Instagram**: Cần **Business Manager Access Token**.

#### **🔹 5. Cấu Hình Schedule Trigger**
- **Daily Content Scheduler**:
  - **Lịch trình**: Ví dụ: `09:00 AM hàng ngày`.
- **Video Processing Scheduler**:
  - **Lịch trình**: Ví dụ: `10:00 AM hàng ngày`.

## **✍️ Mẹo & Gợi Ý Nâng Cao**

### **🔹 1. Tối Ưu Hóa Prompt cho Sora 2**
- **Sử dụng node `AI Script & Prompt Agent`** để tự động sinh **prompt chi tiết** từ ý tưởng viral.
- **Cập nhật mô tả Cameos** trong header HTTP để video có **giọng điệu nhất quán**.

### **🔹 2. Theo Dõi Log & Báo Cáo**
- **Thêm node `Set`** sau `Update Success/Error` để **lưu log chi tiết** vào Google Sheets.
- **Tạo báo cáo hàng tuần** bằng **Google Data Studio** từ dữ liệu Sheets.

### **🔹 3. Tích Hợp Slack/Telegram**
- **Thêm node `Slack`** để **báo cáo thành công/thất bại** tức thời.
- **Cấu hình webhook** từ Slack/Telegram để **nhận thông báo** khi video được sinh/xong.

### **🔹 4. Tự Động Chọn Nền Tảng Phù Hợp**
- **Sử dụng node `Switch`** để **lựa chọn nền tảng đăng tải** dựa trên **keyword trong ý tưởng viral**.
  - Ví dụ: Nếu ý tưởng có từ khóa `TikTok`, tự động đăng trên TikTok.

### **🔹 5. Cập Nhật Thường Xuyên API Key**
- **Kiểm tra định kỳ** API Key của **Gemini, Sora 2, Blotato** để tránh **ngắt kết nối**.
- **Sử dụng node `Code`** để **kiểm tra trạng thái API** trước khi chạy workflow.
