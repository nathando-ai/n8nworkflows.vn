### 🚀 Cách import & Lưu ý khi "lên đồ"

#### 1. Import Workflow 📥
1. Truy cập vào trang [n8n.io/workflows/5270](https://n8n.io/workflows/5270).
2. Nhấp vào nút "Download" để tải file JSON của workflow.
3. Trong n8n Editor, nhấp vào nút "Import" và chọn file JSON đã tải về.

#### 2. Các lưu ý (BẮT BUỘC) phải chỉnh 📌
Phân tích cụ thể các node quan trọng cần cấu hình trong workflow:
- **Test IF**: Node điều kiện để kiểm tra logic trong workflow.
- **Test Node**: Các node noOp để thực hiện các tác vụ kiểm tra.
- **Schedule Trigger**: Node kích hoạt theo lịch trình.
- **Manual Trigger**: Node kích hoạt thủ công để chạy workflow.

#### 3. Kích hoạt ⚡️
- Test run dữ liệu mẫu.
- Bật Active workflow.

### ✍️ Mẹo & gợi ý nâng cao
- Sử dụng phím tắt `Ctrl + S` để lưu workflow thường xuyên.
- Sử dụng phím tắt `P` để ghim dữ liệu của node để dễ dàng theo dõi.
- Sử dụng phím tắt `Shift + Alt + T` để sắp xếp lại các node đã chọn.
