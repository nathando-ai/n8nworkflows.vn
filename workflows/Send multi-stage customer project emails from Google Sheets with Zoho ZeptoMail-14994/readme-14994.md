### 🚀 Cách import & Lưu ý khi "lên đồ"

#### 1. Import Workflow 📥
Hướng dẫn import từ file JSON hoặc copy/paste JSON vào n8n Editor.

#### 2. Các lưu ý (BẮT BUỘC) phải chỉnh 📌
Phân tích cụ thể các node quan trọng cần cấu hình trong workflow:
- **Google Sheets**: Cấu hình credentials và chọn sheet chứa dữ liệu khách hàng
- **Zoho ZeptoMail**: Cấu hình credentials và chọn template email
- **Schedule Trigger**: Thiết lập thời gian gửi email
- **Filter**: Lọc dữ liệu khách hàng theo điều kiện cụ thể
- **Split In Batches**: Chia dữ liệu thành các batch để gửi email
- **Wait**: Thiết lập thời gian chờ giữa các giai đoạn email

#### 3. Kích hoạt ⚡️
- Test run dữ liệu mẫu.
- Bật Active workflow.
