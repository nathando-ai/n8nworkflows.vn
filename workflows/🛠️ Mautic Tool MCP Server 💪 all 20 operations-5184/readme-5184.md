### 🚀 Cách import & Lưu ý khi "lên đồ"

#### 1. Import Workflow 📥
1. Truy cập vào n8n Editor của bạn
2. Click vào "Import from URL" trong menu Workflows
3. Dán link: https://n8n.io/workflows/5184
4. Click "Import" để hoàn tất

#### 2. Các lưu ý (BẮT BUỘC) phải chỉnh 📌
1. **Node Mautic Tool MCP Server**:
   - Chọn credentials cho Mautic
   - Điền API Key của Mautic vào trường tương ứng

2. **Các node thao tác với Contact**:
   - Đảm bảo các trường thông tin như email, tên, số điện thoại được điền đầy đủ
   - Kiểm tra định dạng dữ liệu trước khi chạy workflow

3. **Các node gửi email**:
   - Xác minh template email đã được thiết lập trong Mautic
   - Kiểm tra danh sách nhận email trước khi gửi

4. **Các node quản lý Campaign**:
   - Đảm bảo ID campaign được nhập chính xác
   - Kiểm tra danh sách contact trước khi thêm vào campaign

#### 3. Kích hoạt ⚡️
1. Chạy test với dữ liệu mẫu để kiểm tra kết nối
2. Sau khi xác nhận hoạt động bình thường, bật Active workflow
3. Theo dõi kết quả thông qua log của n8n
