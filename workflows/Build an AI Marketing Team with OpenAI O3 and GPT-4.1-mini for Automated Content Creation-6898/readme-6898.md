## **🚀 Cách Import & Cấu Hình Workflow**

### **1. Import Workflow từ File JSON 📥**
:::note[**Bước 1: Tải Workflow**]
- Tải file JSON từ [n8n.io/workflows/6898](https://n8n.io/workflows/6898) (hoặc liên hệ tác giả Yaron Been để lấy file).
- **Cách import**:
  1. Mở **n8n Editor** trên VPS của bạn.
  2. Nhấp vào **"Import"** ở góc trên bên phải.
  3. Chọn file JSON đã tải và nhấp **"Import"**.
  4. Workflow sẽ xuất hiện với **16 node** như trong danh sách dưới đây.
:::

### **2. Các Lưu Ý BẮT BUỘC Phải Chỉnh 📌**
Workflow này bao gồm **7 agent AI** (CMO + 6 chuyên gia) và **6 mô hình OpenAI** (O3 + GPT-4.1-mini). Dưới đây là **các node quan trọng cần cấu hình**:

#### **🔑 Node "When chat message received" (Trigger)**
- **Loại node**: `chatTrigger` (khởi động workflow khi nhận tin nhắn).
- **Cấu hình**:
  - Chọn **credentials** là **n8n-default** (mặc định).
  - **Lưu ý**: Sau khi import, node này sẽ tự động tạo **URL Webhook** để các sếp gửi yêu cầu. Ví dụ:
    ```
    https://tên-domain-n8n.com/webhook/your-webhook-id
    ```
  - **Test**: Gửi một tin nhắn mẫu như:
    ```
    "Tạo một bài blog SEO về 'cách tự động hóa marketing với n8n'"
    ```
    và kiểm tra workflow có hoạt động không.

#### **🤖 Node "CMO Agent" (O3 Model)**
- **Loại node**: `agent` (mô hình O3 - cao cấp nhất).
- **Cấu hình**:
  - **Credentials**: Chọn `openAiApi` (đã cấu hình trước khi import).
  - **Model**: Đã mặc định là `o3` (không cần thay đổi).
  - **Lưu ý**:
    - **O3 là mô hình cao cấp**, chi phí cao hơn GPT-4.1-mini. Sử dụng khi cần **chiến lược marketing phức tạp**.
    - Nếu không muốn dùng O3, có thể thay bằng `gpt-4.1-mini` (nhưng chất lượng chiến lược sẽ giảm).

#### **📝 Node "Copywriter Agent", "SEO Content Writer", "Email Marketing Specialist", "Social Media Manager", "Facebook Ads Copywriter", "Brand Voice Specialist"**
- **Loại node**: `agentTool` (mô hình GPT-4.1-mini).
- **Cấu hình**:
  - **Credentials**: Chọn `openAiApi`.
  - **Model**: Đã mặc định là `gpt-4.1-mini` (tốt nhất cho hiệu suất chi phí).
  - **Lưu ý**:
    - Mỗi agent có **prompt riêng** để tối ưu hóa công việc:
      - **Copywriter**: Viết copy marketing, landing page.
      - **SEO Content Writer**: Tạo bài blog SEO với từ khóa cụ thể.
      - **Email Specialist**: Tạo email drip campaign.
      - **Social Media Manager**: Tạo nội dung cho Facebook, Instagram, LinkedIn.
      - **Facebook Ads Copywriter**: Viết copy quảng cáo Facebook hiệu quả.
      - **Brand Voice Specialist**: Đảm bảo tính nhất quán về giọng điệu brand.

#### **🔄 Node "OpenAI Chat Model" (6 node)**
- **Loại node**: `lmChatOpenAi` (gọi API OpenAI).
- **Cấu hình**:
  - **Credentials**: Chọn `openAiApi`.
  - **Model**:
    - **O3**: Sử dụng cho **CMO Agent** (node `OpenAI Chat Model1`).
    - **GPT-4.1-mini**: Sử dụng cho **6 chuyên gia** (node `OpenAI Chat Model2` đến `OpenAI Chat Model6`).
  - **Lưu ý**:
    - **API Key**: Đảm bảo đã điền đúng trong **Credentials** của n8n.
    - **Token Limit**: Nếu nội dung quá dài, có thể gặp lỗi. Thêm **node "Set"** để giới hạn số token.

## **✍️ Mẹo & Gợi Ý Nâng Cao**
:::tip[**CÁCH SỬ DỤNG HIỆU QUẢ NHẤT**]
1. **Kết nối với Slack/Telegram**:
   - Sử dụng **node Slack** hoặc **Telegram Bot** để nhận thông báo khi workflow hoàn thành.
   - Ví dụ: Khi AI tạo xong bài blog, nó sẽ gửi link qua Slack.

2. **Lưu lịch sử nội dung**:
   - Kết nối với **Google Sheets** hoặc **Notion** để lưu tất cả nội dung tạo ra.
   - Sử dụng **node "Google Sheets"** để ghi dữ liệu vào sheet.

3. **Gửi báo cáo định kỳ**:
   - Tạo **workflow phụ** để gửi báo cáo tuần/month về:
     - Số lượng nội dung tạo ra.
     - Chi phí API sử dụng.
     - Kết quả SEO (nếu có).

4. **Tối ưu chi phí OpenAI**:
   - **Cache kết quả**: Nếu cùng một yêu cầu, AI trả lời giống nhau, có thể lưu kết quả trước.
   - **Sử dụng GPT-4.1-mini nhiều hơn O3**: O3 chỉ dùng cho CMO, còn các chuyên gia dùng GPT-4.1-mini để tiết kiệm.

5. **Cá nhân hóa brand voice**:
   - Thêm **node "Set"** trước mỗi agent để truyền **giọng điệu brand** cụ thể.
   - Ví dụ: Nếu brand là **chuyên nghiệp**, thêm prompt:
     ```
     "Tôi là một chuyên gia marketing với giọng điệu chuyên nghiệp và rõ ràng. Tất cả nội dung phải phù hợp với brand [Tên Brand]."
     ```
