### 🚀 Cách import & Lưu ý khi "lên đồ"

#### 1. Import Workflow 📥
1. Truy cập vào trang [Airtop Tool MCP Server Workflow](https://n8n.io/workflows/5334)
2. Click vào nút "Download" để tải file JSON của workflow
3. Trong n8n Editor, click vào "Import from File" và chọn file JSON vừa tải về
4. Hoặc copy toàn bộ nội dung JSON và paste vào n8n Editor

#### 2. Các lưu ý (BẮT BUỘC) phải chỉnh 📌
Phân tích cụ thể các node quan trọng cần cấu hình trong workflow:
- **Airtop Tool MCP Server**: Node chính để kết nối với dịch vụ Airtop Tool. Các sếp cần cung cấp API key hợp lệ trong phần credentials.
- **Query page**: Cấu hình URL và các tham số truy vấn cần thiết.
- **Smart scrape page**: Thiết lập các selector để trích xuất dữ liệu từ trang web.
- **Create a session**: Cấu hình các thông số cho phiên làm việc mới.
- **Load a page**: Cung cấp URL của trang cần tải.

#### 3. Kích hoạt ⚡️
- Test run dữ liệu mẫu để đảm bảo workflow hoạt động đúng.
- Bật Active workflow để bắt đầu tự động hóa các thao tác.
