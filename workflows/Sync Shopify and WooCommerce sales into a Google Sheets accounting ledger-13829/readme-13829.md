### 🚀 Cách import & Lưu ý khi "lên đồ"

#### 1. Import Workflow 📥
Hướng dẫn import từ file JSON hoặc copy/paste JSON vào n8n Editor.

#### 2. Các lưu ý (BẮT BUỘC) phải chỉnh 📌
Phân tích cụ thể các node quan trọng cần cấu hình trong workflow:
- **Shopify Trigger**: Cấu hình để lấy dữ liệu bán hàng từ Shopify.
- **WooCommerce Trigger**: Cấu hình để lấy dữ liệu bán hàng từ WooCommerce.
- **Google Sheets**: Cấu hình để lưu dữ liệu vào Google Sheets.

#### 3. Kích hoạt ⚡️
- Test run dữ liệu mẫu.
- Bật Active workflow.
