### 🔧 **Yêu Cầu Cần Thiết**
Để workflow này hoạt động, các sếp cần chuẩn bị:
- **Tài khoản Replicate API**:
  - Đăng ký tại [Replicate](https://replicate.com/) và lấy **API Token** của mình.
  - **Lưu ý**: API Token này phải được bảo mật và không chia sẻ công khai.
- **File âm thanh (audio)**:
  - Định dạng: MP3, WAV (không quá 15 giây cho chất lượng tốt nhất).
  - Nguồn: Âm thanh của các sếp hoặc âm thanh đã có sẵn (ví dụ: giọng nói đọc script).
- **Hình ảnh (image)**:
  - Hình ảnh chứa **người hoặc nhân vật** để AI tạo động tác phù hợp.
  - Kích thước khuyến nghị: 1080p (hoặc cao hơn) để đảm bảo chất lượng video cuối cùng.
- **n8n Self-hosted**:
  - Workflow này **không chạy được** trên phiên bản n8n miễn phí (cloud). Các sếp cần **self-host** trên VPS.

### 🚀 **Cách Import & Lưu Ý Khi "Lên Đồ"**

#### **1. Import Workflow 📥**
Các sếp có thể import workflow từ file JSON hoặc copy/paste JSON vào **n8n Editor**:
- **Tải file JSON** từ [link gốc](https://n8n.io/workflows/6788) hoặc sử dụng mã JSON dưới đây.
- **Cách import**:
  1. Mở **n8n Editor** trên VPS của mình.
  2. Nhấn **Import** (hoặc **Create New Workflow** > **Import**).
  3. Chọn file JSON hoặc dán mã JSON vào ô **Paste JSON**.
  4. Nhấn **Import** để hoàn tất.

#### **2. Các Lưu Ý BẮT BUỘC Phải Chỉnh 📌**
Sau khi import, các sếp cần **cấu hình lại các node quan trọng** như sau:

##### **A. Node "Set API Token"**
- **Tên node**: `Set API Token`
- **Cách chỉnh**:
  1. Nhấp chuột phải vào node này > **Edit**.
  2. Trong phần **JSON**, thay thế giá trị `YOUR_REPLICATE_API_TOKEN` bằng **API Token** của mình (đã lấy từ Replicate).
  3. **Lưu ý**:
     - API Token **không được chia sẻ** với ai.
     - Nếu token hết hạn hoặc bị cấm, workflow sẽ báo lỗi.

##### **B. Node "Set Video Parameters"**
- **Tên node**: `Set Video Parameters`
- **Cách chỉnh**:
  1. Nhấp chuột phải > **Edit**.
  2. Thay đổi các tham số đầu vào theo yêu cầu:
     - **`audio`**: Đường dẫn đến file âm thanh (ví dụ: `https://tino.vn/audio.mp3`).
     - **`image`**: Đường dẫn đến hình ảnh (ví dụ: `https://tino.vn/image.jpg`).
  3. **Lưu ý**:
     - Đảm bảo file âm thanh và hình ảnh **đang hoạt động** (không bị lỗi 404).
     - Nếu muốn thử nghiệm, các sếp có thể sử dụng file mẫu từ [Replicate](https://replicate.com/bytedance/omni-human).

##### **C. Node "Manual Trigger"**
- **Tên node**: `Manual Trigger`
- **Cách hoạt động**:
  - Node này **không cần chỉnh sửa**, chỉ cần nhấn **Run Workflow** (hoặc kích hoạt bằng API nếu tự động hóa).
  - **Lưu ý**: Nếu muốn tự động hóa, các sếp có thể kết nối với **webhook** hoặc **schedule trigger** trong n8n.

##### **D. Node "Wait 5s" và "Wait 10s"**
- **Tên node**: `Wait 5s` và `Wait 10s`
- **Cách chỉnh**:
  - Các node này **không cần chỉnh sửa** vì đã được cấu hình để phù hợp với tốc độ API của Replicate.
  - Nếu workflow chạy chậm hơn, các sếp có thể tăng thời gian chờ (ví dụ: từ 5s → 10s).

##### **E. Node "Log Request" (Code Node)**
- **Tên node**: `Log Request`
- **Cách chỉnh**:
  - Node này **log** tất cả yêu cầu API để theo dõi lỗi.
  - **Không cần chỉnh sửa** trừ khi các sếp muốn thêm thông tin log khác.

#### **3. Kích Hoạt ⚡️ Workflow**
Sau khi cấu hình xong:
1. **Test Run** với dữ liệu mẫu:
   - Nhấn **Run Workflow** và chọn **Manual Trigger**.
   - Kiểm tra các node có hoạt động không lỗi.
2. **Bật Active**:
   - Sau khi test thành công, chuyển trạng thái workflow từ **Inactive** sang **Active**.

### ✍️ **Mẹo & Gợi Ý Nâng Cao**
Sau khi workflow chạy được, các sếp có thể:
1. **Tích Hợp với Slack/Telegram**:
   - Sử dụng node **Slack** hoặc **Telegram Bot** để thông báo kết quả video đã tạo.
   - Ví dụ: Khi video hoàn thành, gửi tin nhắn vào nhóm Slack với link video.

2. **Lưu Log & Báo Cáo**:
   - Sử dụng node **Google Sheets** hoặc **Notion** để lưu lịch sử tạo video.
   - Ví dụ: Lưu thông tin như tên video, thời gian tạo, đường dẫn video, và trạng thái (thành công/thất bại).

3. **Tự Động Hoá Từ File Local**:
   - Nếu các sếp lưu file âm thanh và hình ảnh trên **Google Drive** hoặc **Dropbox**, có thể sử dụng node **Google Drive** hoặc **Dropbox** để tải file tự động vào workflow.

4. **Tối Ưu Hóa API Key**:
   - Sử dụng **n8n Credentials** để lưu API Token một cách an toàn.
   - Cách làm:
     1. Trong n8n Editor, nhấn **Credentials** (phía trên).
     2. Thêm một **New Credential** với tên `replicate_api`.
     3. Nhập API Token vào và lưu.
     4. Trong node **Set API Token**, thay vì nhập trực tiếp, chọn **Use Credential** và chọn `replicate_api`.

5. **Xử Lý Lỗi Tự Động**:
   - Thêm node **Email** hoặc **Slack Alert** để thông báo khi workflow thất bại.
   - Ví dụ: Nếu video không tạo được, gửi email cảnh báo cho team.
