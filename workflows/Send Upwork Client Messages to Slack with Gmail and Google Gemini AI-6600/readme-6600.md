### 🚀 Cách import & Lưu ý khi "lên đồ"

#### 1. Import Workflow 📥
1. Truy cập vào trang [n8n.io/workflows/6600](https://n8n.io/workflows/6600).
2. Nhấp vào nút "Import" để tải xuống file JSON của workflow.
3. Trong n8n Editor, nhấp vào nút "Import from File" và chọn file JSON đã tải xuống.

#### 2. Các lưu ý (BẮT BUỘC) phải chỉnh 📌
- **Gmail Trigger**: Cấu hình tài khoản Gmail để theo dõi tin nhắn từ Upwork.
- **Code**: Chỉnh sửa mã JavaScript để xử lý dữ liệu từ Gmail.
- **Information Extractor**: Cấu hình để trích xuất thông tin cần thiết từ tin nhắn.
- **Google Gemini Chat Model**: Cấu hình API Key của Google Gemini để sử dụng công nghệ AI.
- **Send to Slack**: Cấu hình tài khoản Slack để nhận thông báo.

#### 3. Kích hoạt ⚡️
1. Nhấp vào nút "Execute Workflow" để kiểm tra workflow với dữ liệu mẫu.
2. Nhấp vào nút "Activate" để kích hoạt workflow và bắt đầu theo dõi tin nhắn từ Upwork.
