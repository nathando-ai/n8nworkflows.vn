### 🚀 Cách import & Lưu ý khi "lên đồ"

#### 1. Import Workflow 📥
Hướng dẫn import từ file JSON hoặc copy/paste JSON vào n8n Editor.

#### 2. Các lưu ý (BẮT BUỘC) phải chỉnh 📌
Phân tích cụ thể các node quan trọng cần cấu hình trong workflow:
- **Shopify Trigger**: Cấu hình để theo dõi sự kiện sản phẩm mới
- **Perplexity Node**: Cấu hình API Key và tham số truy vấn
- **Google Gemini Node**: Cấu hình API Key và prompt cho nội dung SEO
- **Google Sheets Node**: Cấu hình ID bảng tính và tên sheet để lưu nội dung

#### 3. Kích hoạt ⚡️
- Test run dữ liệu mẫu.
- Bật Active workflow.
