### 🎯 Kết quả các sếp nhận được
:::tip[LỢI ÍCH CỐT LÕI]
- Tiết kiệm thời gian: Tự động tóm tắt nội dung video YouTube trong Discord mà không cần can thiệp thủ công.
- Tăng hiệu quả làm việc: Nhận được bản tóm tắt chất lượng cao từ AI Gemini ngay trong kênh Discord.
- Lưu trữ dữ liệu: Dữ liệu tóm tắt được lưu trữ an toàn trên Supabase.

### 🔧 Yêu cầu cần thiết
:::info[CHUẨN BỊ]
- Tài khoản Discord và quyền quản trị kênh.
- API Key của Google Gemini.
- Tài khoản Supabase và thông tin kết nối cơ sở dữ liệu.
:::

### 🚀 Cách import & Lưu ý khi "lên đồ"

#### 1. Import Workflow 📥
Hướng dẫn import từ file JSON hoặc copy/paste JSON vào n8n Editor.

#### 2. Các lưu ý (BẮT BUỘC) phải chỉnh 📌
Phân tích cụ thể các node quan trọng cần cấu hình trong workflow:
- **Discord Trigger**: Cấu hình kênh Discord để nhận thông báo khi có video mới.
- **Google Gemini**: Cấu hình API Key và prompt để tóm tắt nội dung.
- **Supabase**: Cấu hình thông tin kết nối cơ sở dữ liệu để lưu trữ dữ liệu tóm tắt.

#### 3. Kích hoạt ⚡️
- Test run dữ liệu mẫu.
- Bật Active workflow.
