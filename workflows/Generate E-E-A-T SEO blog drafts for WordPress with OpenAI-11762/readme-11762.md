# 🚀 **Tự Động Hóa Viết Bài Blog SEO Chất Lượng E-E-A-T cho WordPress với OpenAI**

## **Nỗi Đau Của Các Sếp**
Viết bài blog SEO chất lượng là một quá trình tốn thời gian, đòi hỏi kiến thức về **SEO, E-E-A-T (Experience, Expertise, Authority, Trustworthiness)**, và khả năng tổ chức nội dung logic. Các sếp thường phải:
- **Tìm kiếm và chọn chủ đề** phù hợp với từ khóa.
- **Nghiên cứu đối thủ** và xây dựng cấu trúc bài viết.
- **Viết nội dung** với phong cách phù hợp với đối tượng mục tiêu.
- **Tối ưu metadata** (tiêu đề, mô tả, từ khóa) để xếp hạng cao trên Google.
- **Tạo hình ảnh nổi bật** và upload lên WordPress.
- **Kiểm tra và chỉnh sửa** trước khi xuất bản.

**Kết quả?** Thời gian và công sức bị "chìm" trong quá trình thủ công, trong khi chất lượng bài viết không đảm bảo nhất quán.

### **📌 Cách Tạo Application Password cho WordPress**
1. Đăng nhập vào **WordPress Dashboard** → **Người dùng** → **Tạo người dùng mới** (nếu chưa có).
2. Chọn **Người dùng admin** → **Thêm mới**.
3. Cuộn xuống phần **"Application Password"** → Nhập tên (ví dụ: `n8n-auto-blog`) → **Tạo mật khẩu**.
4. **Lưu mật khẩu này** (dạng: `ABCD EFGH IJKL MNOP`) và **điền vào n8n** khi cấu hình WordPress credentials.

### **2. Các Lưu Ý (BẮT BUỘC) Phải Chỉnh 📌**
Workflow có **12 node** quan trọng, các sếp cần cấu hình như sau:

#### **🔹 Node 1: Form (formTrigger)**
- **Đặt tên**: `plots-eeat-blog` (không đổi).
- **Cấu trúc form**:
  - **Topic** (Chủ đề bài viết).
  - **Keywords** (Từ khóa SEO).
  - **Audience** (Đối tượng mục tiêu).
  - **Tone** (Phong cách viết: chuyên nghiệp, thân thiện, giáo dục...).
  - **Word Count** (Số từ yêu cầu).
  - **Author Details** (Thông tin tác giả, nếu cần).
  - **Image Prompt** (Mô tả hình ảnh nổi bật, ví dụ: "Hình ảnh về bất động sản đô thị").

#### **🔹 Node 2: Store Values (set)**
- **Lưu trữ dữ liệu** từ form để các node sau sử dụng.
- **Không cần chỉnh sửa**, chỉ cần **đảm bảo kết nối** với node Form.

#### **🔹 Node 3 & 4: AI Create Metadata + Outline (openAi)**
- **API Key OpenAI**:
  - Đăng nhập [OpenAI](https://platform.openai.com/) → **API Keys** → **Tạo API Key**.
  - **Điền vào n8n** khi cấu hình node OpenAI (trong **Credentials**).
- **Prompt mẫu**:
  ```json
  "Create a detailed SEO metadata and outline for a blog post about {{ $json.topic }}. Include:
  - Title (with primary keyword)
  - Meta description (under 160 chars)
  - H1, H2, H3 headings
  - Introduction (100 words)
  - Main sections with bullet points
  - Conclusion (50 words)
  - Trust signals (authority, expertise, citations)
  - Word count: {{ $json.wordCount }}
  - Tone: {{ $json.tone }}"
  ```

#### **🔹 Node 5: Validate Output (if)**
- **Kiểm tra** nếu metadata hoặc outline **không hợp lệ** (ví dụ: thiếu tiêu đề, từ khóa).
- **Nếu sai**, workflow sẽ **dừng lại** và trả về lỗi (node **Respond: Error**).

#### **🔹 Node 6: AI Write Full Article (openAi)**
- **Prompt mẫu**:
  ```json
  "Write a full blog post about {{ $json.topic }} based on the following outline:
  {{ $json.outline }}
  Requirements:
  - Word count: {{ $json.wordCount }}
  - Tone: {{ $json.tone }}
  - Include all H2/H3 headings from the outline
  - Use {{ $json.keywords }} naturally
  - Write in clean HTML format (no extra tags)
  - Add internal/external links if relevant
  - End with a strong CTA"
  ```

#### **🔹 Node 7: Compile Post (code)**
- **Chức năng**: **Gộp** metadata, nội dung, và hình ảnh thành **dữ liệu chuẩn WordPress**.
- **Không cần chỉnh sửa**, chỉ cần **đảm bảo kết nối** với node OpenAI (nội dung) và node Generate Featured Image.

#### **🔹 Node 8: Create WP Draft (wordpress)**
- **Cấu hình WordPress Credentials**:
  - **URL WordPress**: `https://tênmien.com/wp-json/wp/v2/posts`.
  - **Application Password**: (Đã tạo ở trên).
  - **Test connection** để đảm bảo kết nối thành công.

#### **🔹 Node 9 & 10: Generate Featured Image & Upload (openAi + httpRequest)**
- **Node 9 (Generate Featured Image)**:
  - **Prompt**: `=Featured image for a blog about: {{ $json.title }}. {{ $json.imagePrompt }}. Realistic, high quality, no text, landscape composition.`
  - **Output**: Lấy URL hình ảnh từ OpenAI DALL·E.
- **Node 10 (Upload to WordPress)**:
  - **Upload hình ảnh** từ URL vào WordPress.
  - **Đảm bảo node này kết nối với WordPress Credentials**.

#### **🔹 Node 11: Assign Featured Image (httpRequest)**
- **Gán hình ảnh** vừa upload vào **bản nháp WordPress**.
- **URL API**: `https://tênmien.com/wp-json/wp/v2/posts/{{ $json.postId }}/media`.

#### **🔹 Node 12: Respond (respondToWebhook)**
- **Trả về kết quả**:
  - **Thành công**: `Bài viết đã tạo thành công! ID: {{ $json.postId }}`.
  - **Thất bại**: `Có lỗi xảy ra: {{ $json.error }}`.
