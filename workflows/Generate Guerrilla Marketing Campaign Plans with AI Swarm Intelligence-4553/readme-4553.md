### 🚀 Cách import & Lưu ý khi "lên đồ"

#### 1. Import Workflow 📥
- Tải file JSON của workflow từ nguồn cung cấp (hoặc copy toàn bộ JSON).
- Mở giao diện n8n Editor, nhấn vào **Add workflow** -> Chọn dấu ba chấm ở góc trên bên phải -> **Import from File / Clipboard** và dán đoạn mã vào.

#### 2. Các lưu ý (BẮT BUỘC) phải chỉnh 📌
- **OpenAI Chat Model Node:** Cần kết nối thông tin xác thực (`credentials`) bằng OpenAI API Key của các sếp. Mặc định workflow đang sử dụng model `gpt-4.1-mini` (có thể thay đổi linh hoạt sang các model mạnh hơn như GPT-4o nếu muốn tối ưu chất lượng).
- **Chat Trigger & Agents (Introduction Writer, Campaign Definition Agent, Market Analyst, Idea Generator...):** Đây là chuỗi agent phối hợp nhịp nhàng. Các sếp có thể tinh chỉnh system prompt bên trong từng agent nếu muốn định hướng văn phong hoặc phong cách marketing phù hợp hơn với thị trường ngách của mình.
- **Swarm Intelligence Section:** Bao gồm phần đánh giá ý tưởng (`Idea is good enough?` và `Market Analyst / Idea Generator`). Nếu các sếp đã có sẵn ý tưởng cụ thể và không cần AI brainstorming từ đầu, có thể tạm ẩn hoặc tắt cụm node này để tối ưu tốc độ chạy.

#### 3. Kích hoạt ⚡️
- Nhấn **Chat trigger** hoặc mở giao diện chat tích hợp trong n8n để nhập thử thông tin doanh nghiệp (ví dụ: mô tả sản phẩm, ngân sách, khách hàng mục tiêu).
- Nhấn **Execute Workflow** để test thử luồng chạy của hệ thống đa tác nhân.
- Sau khi kiểm tra dữ liệu trả về mượt mà, bật công tắc **Active** để đưa workflow vào trạng thái sẵn sàng hoạt động liên tục.

### ✍️ Mẹo & gợi ý nâng cao
- **Tích hợp kênh thông báo:** Thay vì chỉ tải file qua node `Final result` (convertToFile), các sếp có thể gắn thêm node **Telegram** hoặc **Slack** để tự động gửi bản kế hoạch hoàn chỉnh trực tiếp về nhóm chat ngay khi AI chạy xong.
- **Lưu trữ tự động:** Kết nối đầu ra của kết quả vào **Google Sheets** hoặc **Notion** để lưu trữ lịch sử các chiến dịch marketing đã tạo, tiện cho việc tra cứu sau này.
- **Tùy biến LLM:** Các sếp hoàn toàn có thể thay thế OpenAI bằng các mô hình open-source chạy local qua Ollama để tiết kiệm chi phí gọi API nếu chạy số lượng lớn.
