### 🔧 Yêu cầu cần thiết
:::info[CHUẨN BỊ]
- Tài khoản Twitch Developer (để lấy OAuth Token).

- Tài khoản Instagram (để chia sẻ clip).

### 🚀 Cách import & Lưu ý khi "lên đồ"

#### 1. Import Workflow 📥
Hướng dẫn import từ file JSON hoặc copy/paste JSON vào n8n Editor.

#### 2. Các lưu ý (BẮT BUỘC) phải chỉnh 📌
Phân tích cụ thể các node quan trọng cần cấu hình trong workflow:
- **Schedule Trigger**: Cấu hình thời gian và tần suất tạo clip.
- **Obtain your Twitch OAuth Token**: Điền thông tin tài khoản Twitch và lấy OAuth Token.
- **Fetch Streamer Clips**: Cấu hình URL và tham số để lấy clip từ streamer.
- **Filter Best Clips**: Thiết lập số lượng clip tốt nhất để xử lý.
- **Download and Edit Clips**: Cấu hình các công cụ chỉnh sửa clip.
- **Upload to your YouTube Account**: Điền thông tin tài khoản YouTube và cấu hình chia sẻ.
- **Post To Instagram**: Cấu hình chia sẻ clip lên Instagram.
- **Post To TikTok**: Cấu hình chia sẻ clip lên TikTok.

#### 3. Kích hoạt ⚡️
- Test run dữ liệu mẫu.
- Bật Active workflow.
