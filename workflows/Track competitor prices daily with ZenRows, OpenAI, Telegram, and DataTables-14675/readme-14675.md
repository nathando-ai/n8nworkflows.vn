### 🚀 Cách import & Lưu ý khi "lên đồ"

#### 1. Import Workflow 📥
Để import workflow này vào n8n của các sếp, các sếp có thể làm theo các bước sau:

1. Truy cập vào trang web của n8n.
2. Nhấp vào nút "Import from URL" trên giao diện n8n.
3. Dán liên kết sau vào ô nhập liệu: [https://n8n.io/workflows/14675](https://n8n.io/workflows/14675)
4. Nhấp vào nút "Import" để hoàn tất quá trình import.

#### 2. Các lưu ý (BẮT BUỘC) phải chỉnh 📌
Các sếp cần chú ý cấu hình các node sau trong workflow:

- **Schedule Trigger**: Cấu hình thời gian chạy workflow hàng ngày.
- **Zenrows check product**: Cấu hình URL của sản phẩm cần theo dõi.
- **OpenAI Chat Model**: Cấu hình API key của OpenAI và prompt cho việc phân tích dữ liệu.
- **Send a message**: Cấu hình địa chỉ email để nhận báo cáo.
- **Send a text message**: Cấu hình thông tin tài khoản Telegram để nhận thông báo.
- **Update row(price chenged)**: Cấu hình thông tin tài khoản DataTables để lưu trữ dữ liệu.
- **Get row(price url)**: Cấu hình thông tin tài khoản DataTables để lấy dữ liệu.

#### 3. Kích hoạt ⚡️
Sau khi cấu hình xong, các sếp cần thực hiện các bước sau để kích hoạt workflow:

1. Nhấp vào nút "Execute Node" để kiểm tra workflow với dữ liệu mẫu.
2. Nhấp vào nút "Activate" để kích hoạt workflow và bắt đầu theo dõi giá hàng ngày.
