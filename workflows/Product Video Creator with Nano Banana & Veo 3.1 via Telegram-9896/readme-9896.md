# 🚀 **Tự Động Hoá Sáng Tạo Video Marketing Cho Sản Phẩm Với AI Nano Banana & Veo 3.1**

### **2. Các Lưu Ý (BẮT BUỘC) Phải Chỉnh 📌**

#### **🔹 Cấu Hình Telegram Trigger**
- **Node**: `Telegram Trigger Received`
  - **Credentials**: Chọn `telegramApi` (đã cấu hình trước khi import).
  - **Chat ID**: Để trống hoặc nhập chat ID cụ thể (nếu muốn chỉ nhận từ một chat).
  - **Update Type**: Chọn `message` để nhận ảnh từ người dùng.

#### **🔹 Cấu Hình Nano Banana (Google Gemini)**
- **Node**: `AI Design Analysis` và `Generate Enhanced Image`
  - **Credentials**: Chọn `googlePalmApi` (đã cấu hình API Key).
  - **Prompt**: Workflow đã tự động hóa prompt, nhưng các sếp có thể **cập nhật** trong node `Prepare API Payload` (node `code`).
    - Ví dụ: Thay đổi **aspect ratio**, **độ dài video**, hoặc **thêm watermark**.
  - **Resource**: Chọn `image` để phân tích ảnh sản phẩm.

#### **🔹 Cấu Hình Veo 3.1**
- **Node**: `Initiate veo 3.1 Video Generation` và `Check Video Status`
  - **Credentials**: Chọn `googlePalmApi` (API Key) và `googleOAuth2Api` (OAuth Token).
  - **API Endpoint**: Workflow đã tự động hóa, nhưng các sếp nên kiểm tra:
    - **Duration**: Đặt thành `8` (giây).
    - **Resolution**: Đặt thành `1080p`.
    - **Audio**: Đặt thành `true` (có âm nhạc).
    - **Format**: Đặt thành `9:16` (vertical).

#### **🔹 Cấu Hình Merge Data**
- **Node**: `Combine Image & Analysis`
  - Kiểm tra **mapping** giữa `image` và `analysis` để đảm bảo dữ liệu truyền đúng.

#### **🔹 Cấu Hình Processing Loop**
- **Node**: `Video Ready Validator` và `Processing Delay (30s)`
  - **Validator**: Kiểm tra `status` từ Veo 3.1.
    - Nếu `status === "ready"`, workflow chuyển sang bước tiếp theo.
    - Nếu `status !== "ready"`, workflow **đợi 30s** và kiểm tra lại.
  - **Lưu ý**: Nếu video mất quá lâu, có thể tăng thời gian chờ trong node `wait`.

#### **🔹 Cấu Hình Gửi Video Trở Lại Telegram**
- **Node**: `Send veo 3.1 video`
  - **Credentials**: Chọn `telegramApi`.
  - **Chat ID**: Để trống để gửi về chat gốc.
  - **Operation**: Chọn `sendVideo`.
  - **File**: Chọn `json` từ node `Convert Base64 to video`.

## ✍️ **Mẹo & Gợi Ý Nâng Cao**

### **1. Tối Ưu Hóa Prompt AI**
- **Node `Prepare API Payload` (code)**: Các sếp có thể **cập nhật prompt** để AI phân tích sản phẩm chi tiết hơn.
  - Ví dụ:
    ```javascript
    // Thêm yêu cầu về chất liệu, màu sắc và góc chụp
    const prompt = `Analyze this product image and provide a detailed creative prompt for a professional product photo.
    - Identify materials: ${item.materials || 'unknown'}
    - Suggest lighting: studio lighting with soft shadows
    - Composition: center the product, use rule of thirds
    - Colors: enhance ${item.colors || 'natural'} tones
    - Generate a 500-word creative prompt for a 9:16 vertical video`;
    ```
- **Kết quả**: Video sẽ có chất lượng cao hơn, phù hợp với thương hiệu.

### **2. Thêm Watermark Cho Video**
- **Node `Prepare API Payload` (code)**: Thêm yêu cầu watermark vào prompt.
  - Ví dụ:
    ```javascript
    const prompt = `... (các yêu cầu cũ) ...
    - Add watermark: "BrandName" in corner, semi-transparent`;
    ```
- **Kết quả**: Video sẽ có logo thương hiệu, phù hợp cho marketing.

### **3. Lưu Log & Theo Dõi Lỗi**
- **Thêm node `stickyNote`** để ghi lại thông tin debug:
  - Ví dụ: Ghi lại thời gian tạo video, status của Veo 3.1, hoặc lỗi nếu có.
- **Node `code`**: Thêm log để theo dõi dữ liệu truyền giữa các node.
  ```javascript
  console.log("Data before Veo API:", JSON.stringify(item));
  ```

### **4. Gửi Video Đến Nhiều Nơi**
- **Node `telegram`**: Thay vì chỉ gửi về chat gốc, các sếp có thể **gửi video đến nhiều chat** hoặc **email**.
  - Sử dụng node `httpRequest` để gửi video đến **Google Drive**, **Dropbox**, hoặc **email** (vía SMTP).

### **5. Tự Động Xóa Ảnh Tạm**
- **Node `code`**: Thêm logic xóa ảnh tạm sau khi video được tạo thành công.
  ```javascript
  // Xóa ảnh Base64 sau khi video được tạo
  if (item.videoStatus === "ready") {
    delete item.imageBase64;
  }
  ```

### **6. Thay Đổi Độ Lâu Video**
- **Node `Initiate veo 3.1 Video Generation`**:
  - Thay đổi `duration` từ `8` sang `4` (giây) nếu muốn video ngắn hơn.
