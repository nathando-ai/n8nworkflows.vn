### 🚀 Cách import & Lưu ý khi "lên đồ"

#### 1. Import Workflow 📥
Hướng dẫn import từ file JSON hoặc copy/paste JSON vào n8n Editor.

#### 2. Các lưu ý (BẮT BUỘC) phải chỉnh 📌
Phân tích cụ thể các node quan trọng cần cấu hình trong workflow:
- **Gmail**: Cấu hình tài khoản Gmail để gửi email.
- **Google Sheets**: Cấu hình tài khoản Google Sheets để lưu danh sách khách hàng.
- **OpenAI**: Cấu hình API Key của OpenAI để sử dụng AI tạo nội dung email.
- **Loop Over Emails**: Cấu hình số lượng email gửi trong mỗi batch.
- **Generate Email content**: Cấu hình prompt để tạo nội dung email.
- **Generate Email Follow-up 1**: Cấu hình prompt để tạo nội dung email theo dõi 1.
- **Generate Email Final Follow-up**: Cấu hình prompt để tạo nội dung email theo dõi cuối cùng.

#### 3. Kích hoạt ⚡️
- Test run dữ liệu mẫu.
- Bật Active workflow.
