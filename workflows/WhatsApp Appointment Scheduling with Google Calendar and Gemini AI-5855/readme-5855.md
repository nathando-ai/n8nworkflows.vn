### 🚀 Cách import & Lưu ý khi "lên đồ"

#### 1. Import Workflow 📥
Để import workflow, các sếp có thể tải file JSON từ [đây](https://n8n.io/workflows/5855) và import vào n8n Editor.

#### 2. Các lưu ý (BẮT BUỘC) phải chỉnh 📌
Phân tích cụ thể các node quan trọng cần cấu hình trong workflow:
- **WhatsApp Trigger**: Cấu hình tài khoản WhatsApp Business API hoặc WhatsApp Business Solution.
- **Google Gemini Chat Model**: Cấu hình API Key của Google Gemini.
- **Google Calendar Tool**: Cấu hình tài khoản Google Calendar và quyền truy cập.
- **AI Agent**: Cấu hình các công cụ và bộ nhớ cho AI Agent.
- **Simple Memory**: Cấu hình bộ nhớ cho AI Agent.

#### 3. Kích hoạt ⚡️
- Test run dữ liệu mẫu.
- Bật Active workflow.
