### 🚀 Cách import & Lưu ý khi "lên đồ"

#### 1. Import Workflow 📥
1. Truy cập vào n8n Editor.
2. Nhấn vào "Import from URL" và dán link: [https://n8n.io/workflows/8648](https://n8n.io/workflows/8648).
3. Hoặc tải file JSON về và import từ file.

#### 2. Các lưu ý (BẮT BUỘC) phải chỉnh 📌
- **Telegram Trigger**: Cấu hình credentials với bot token của bạn.
- **Google Gemini Chat Model**: Cấu hình credentials với API key của Google Gemini.
- **Send a message in Gmail**: Cấu hình credentials với tài khoản Google của bạn.
- **Create an event in Google Calendar**: Cấu hình credentials với tài khoản Google của bạn.
- **Create notes in Notion**: Cấu hình credentials với API key của Notion.

#### 3. Kích hoạt ⚡️
- Test run dữ liệu mẫu.
- Bật Active workflow.
