### 🚀 Cách import & Lưu ý khi "lên đồ"

#### 1. Import Workflow 📥
Hướng dẫn import từ file JSON hoặc copy/paste JSON vào n8n Editor.

#### 2. Các lưu ý (BẮT BUỘC) phải chỉnh 📌
Phân tích cụ thể các node quan trọng cần cấu hình trong workflow:
- **Webhook**: Điểm danh tên node cụ thể từ danh sách nodes được cung cấp (ví dụ: webhook, google sheets, LLM, email, slack...).
  - Path: `/pankstr/mode`
- **AI Agent**: Cấu hình agent với bộ nhớ để tránh lặp lại.
- **Structured Output Parser**: Cấu hình để đầu ra được định dạng thành JSON đơn giản.
- **OpenAI Chat Model**: Chọn credentials và điền tham số (API Key, Model).
  - Model: `gpt-4.1`
- **Flatten JSON**: Sử dụng node Code để làm phẳng JSON đầu ra.

#### 3. Kích hoạt ⚡️
- Test run dữ liệu mẫu.
- Bật Active workflow.
